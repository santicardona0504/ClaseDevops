crea un proyecto de una calculadora web, con una interfaz grafica de pixel art, para todas las operaciones elementales y que tenga un estilo

# Tarea 

Git init: inicializa un repositorio local en git

Git add .: Agrega archivos o modificaciones al area de preparaciones

Git commit: guarda los cambios que tenias en el area de preparaciones 

Git push: envia los commitos guardados en el repositorio creado

Git status: muestra el estado actual del proyecto 

Git diff: muestra los cambios que hizo en los archivos 

Git log: muestra el historial de los commits que hiciste 

Git restore: permite descartar las modificaciones o sacar los archivos.
